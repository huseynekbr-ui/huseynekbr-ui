## 💭 Product Principles

- **Clarity first.** A product should make sense before it makes an impression.
- **Every feature needs a reason.** Build what earns its place.
- **Details build trust.** Small interactions shape the whole experience.
- **Listen before you build.** Understand the need behind the request.
- **Launch is a starting point.** Real use teaches us what comes next.
